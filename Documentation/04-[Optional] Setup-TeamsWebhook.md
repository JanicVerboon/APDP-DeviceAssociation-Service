# Introduction

This chapter documents the steps required to set up the Teams webhook for APDP-DeviceAssociation-Service notifications.

> **Information:** If you do not want to receive notifications in Microsoft Teams, you can skip this step.

## Setup Teams Webhook

1. Open Microsoft Teams and navigate to the channel where you want to add the webhook.
 * Click the three *...* next to the channel name and select **Workflows**.

* ![Image1](/SupportingFiles/04-01.png)

2. Select the **Send webhook alerts to a channel** workflow template.

* ![Image2](/SupportingFiles/04-02.png)

3. Verify that the selected team and channel are correct.
* Click **Save**.

* ![Image3](/SupportingFiles/04-03.png)

4. Give the webhook a unique and identifiable name by clicking **Rename**.
* Click **Save** after renaming the webhook.
* Click **Copy webhook link** and save it in a temporary location; you will need it later.

* ![Image4](/SupportingFiles/04-04.png)

5. **Optional:** If you want to add an additional owner to the flow, scroll down and add co-owners to the webhook.

* ![Image5](/SupportingFiles/04-05.png)

6. Close the Teams workflow setup wizard and make sure you have the webhook link ready for the next step.
